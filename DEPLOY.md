# «Слова для уроков» — как запустить

Что где живёт:
- `Code.gs` — сервер в Google Apps Script, привязан к таблице «Репетитор — слова» на твоём Диске.
- `index.html` — само приложение, публикуется на GitHub Pages (репозиторий `tutor-words`).
- Секреты (токен, ключи) — только в «Свойствах скрипта». Ни в коде, ни на GitHub их нет.

Время: около 40 минут. После каждого шага есть проверка: если она прошла, можно остановиться и продолжить позже.

---

## Шаг 1. Бот — 5 минут

1. В Telegram открой @BotFather → `/newbot`.
2. Имя: «Слова для уроков». Username — любой свободный, на `bot` в конце.
3. Скопируй токен. **Никому его не присылай**, даже Claude.
4. Открой своего нового бота и нажми **«Старт»**. Без этого бот не сможет прислать тебе файл.

## Шаг 2. Таблица и сервер — 15 минут

1. Google Диск → Создать → Google Таблицы → назови «Репетитор — слова».
2. Расширения → **Apps Script**. Удали всё, что есть в `Code.gs`, вставь наш `Code.gs` целиком → **Сохранить**. Проект можно переименовать в «Слова для уроков».
3. Ключ Gemini: aistudio.google.com → **Get API key** → **Create API key** → скопируй.
4. В Apps Script: ⚙️ **Настройки проекта** → внизу **Свойства скрипта** → **Добавить свойство**:

   | Свойство | Значение |
   |---|---|
   | `BOT_TOKEN` | токен из шага 1 |
   | `ALLOWED_IDS` | твой Telegram ID (тот же, что `OWNER_ID` в «Тратах») |
   | `GEMINI_API_KEY` | ключ из AI Studio |
   | `MODELS` | точные имена моделей из AI Studio через запятую, по порядку. Например: `gemini-3.5-flash,gemini-3.6-flash-lite,gemini-3.8-flash` |
   | `GROQ_API_KEY` | *по желанию*: ключ console.groq.com, станет четвёртой запасной моделью другой компании |

5. Вернись к коду. Наверху в списке функций выбери **`setup`** → **Выполнить**. Google попросит доступ: «Проверить разрешения» → твой аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить» (как в «Тратах»).

**✅ Проверка 1 — модели.** Выбери **`testModels`** → Выполнить. Первая строка журнала — «паспорт» ключа, например: `Ключ Gemini: 53 символа, начинается с «AQ.A»`. Сам ключ там не печатается. Дальше будет по строке на модель:
- `✓ gemini-…` с тремя словами — модель работает;
- `✗ … Google не принял ключ … API key not valid` — ошибка в **ключе**, а не в моделях, поэтому остальные модели Gemini уже не проверяются. Открой свойство `GEMINI_API_KEY` и проверь две вещи. Имя свойства должно быть точно `GEMINI_API_KEY`. Значение — сам ключ целиком. У AI Studio бывают ключи вида `AIza…` (39 символов) и `AQ.…` (53 символа). Не название и не ID проекта. Скопируй ключ заново: AI Studio → **Get API key** → нажми на свой ключ → **Copy**. Не помогло — создай новый (**Create API key**) и вставь его;
- `✗ … HTTP 404` — неверное имя модели, исправь `MODELS`;
- `✗ … HTTP 429` — модель перегружена или лимит, бот возьмёт следующую.

Пришли журнал мне. Ключа в журнале нет, только его длина и первые 4 символа.

*По желанию:* **`compareModels`** прогоняет все модели на 10 трудных словах. Там слова, которые пишутся одинаково, а читаются по-разному (`wind`, `lead`, `bow`, `read`), сложная транскрипция и фразовые глаголы. По журналу видно, какая модель ошибается, — так проще выбрать порядок в `MODELS`.

**✅ Проверка 2 — лист Word.** Выбери **`testSheet`** → Выполнить. В чат с ботом придёт «Пробный лист» — полный лист, как будет у сестры. Открой его **на ноутбуке в Word**. Должна быть **одна страница**. Если таблица вылезла на вторую — напиши мне.

## Шаг 3. Веб-приложение — 5 минут

1. **Развертывание → Новое развертывание** → ⚙️ тип «Веб-приложение».
2. Выполнять от имени: **Я**. У кого есть доступ: **Все**. → **Развернуть** → скопируй URL, он заканчивается на `/exec`.
3. «Новое развертывание» делается **один раз**. Когда будешь обновлять код: Сохранить → **Развертывание → Управление развертываниями → карандаш → Версия: Новая версия → Развернуть**. Если нажать «Новое развертывание», адрес сменится, и приложение продолжит ходить на старый.

## Шаг 4. Страница на GitHub — 10 минут

1. github.com → **New repository** → имя `tutor-words` → **Public** → Create.
2. GitHub Desktop → File → Clone repository → `tutor-words`.
3. Положи в папку `index.html`, `Code.gs` и `DEPLOY.md` (последние два — для истории).
4. В `index.html` найди строку `const API_URL = 'PASTE_EXEC_URL_HERE';` и вставь между кавычками адрес из шага 3.
5. Commit → **Push origin**.
6. На github.com: репозиторий → **Settings → Pages** → Source: Deploy from a branch → `main` / `(root)` → Save. Через 1–2 минуты страница будет по адресу `https://vovaod187.github.io/tutor-words/`.

**✅ Проверка:** открой этот адрес в обычном браузере. Должно быть написано **«Открой из Telegram»**. Если видишь «Приложение не настроено» — адрес сервера не вставлен.

## Шаг 5. Кнопка в боте — 3 минуты

@BotFather → `/mybots` → твой бот → **Bot Settings → Menu Button → Configure menu button** → ссылка `https://vovaod187.github.io/tutor-words/` → название **«Слова»**.

**✅ Проверка вживую:** в чате с ботом нажми «Слова» и пройди по шагам:
1. Добавь тестового ученика.
2. Впиши `borrow, give up, bank (берег)` → «Заполнить».
3. Нажми на строку и исправь перевод.
4. Нажми «Сформировать Word» два раза: лист неполный, поэтому бот переспрашивает.
5. Файл придёт в чат.

Тестового ученика потом удали в таблице: строки в листах «Ученики», «Слова» и «Листы». Или напиши «нет» в колонке «активен».

## Шаг 6. Подключить сестру

1. Сестра открывает бота, нажимает **«Старт»**, потом **«Слова»**.
2. Она увидит «Нет доступа» и номер → пусть пришлёт его тебе.
3. Свойства скрипта → `ALLOWED_IDS` → допиши через запятую: `твой_ID, её_ID`. Переразвёртывать не нужно.
4. По желанию: «Настройки доступа» таблицы → её почта → **Редактор**. Тогда она сможет смотреть и править слова прямо в таблице.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «Модели сейчас не отвечают» | Лист «Журнал» в таблице: какая модель и почему. Запусти `testModels`. |
| «Google не принял ключ модели» | Ключ `GEMINI_API_KEY` вставлен неверно — см. «Проверка 1» в шаге 2. |
| «Бот не может прислать файл» | Открыть чат с ботом и нажать «Старт». |
| «Сервер устарел», новые кнопки не работают | Не выпущена новая версия развертывания (шаг 3, пункт 3). |
| Изменения на странице не видны | Кэш: закрой приложение крестиком и открой снова. На ПК — «Перезагрузить страницу». GitHub обновляет страницу до 10 минут. |
| Лист вылез на вторую страницу | В листе «Настройки» поставь `fontSize` = 11 и напиши мне. |
| «Нет доступа» у сестры | Её ID не добавлен в `ALLOWED_IDS` или есть опечатка. |

## Что в таблице

- **Ученики** — имя, уровень. Колонка «активен» = «нет» прячет ученика.
- **Слова** — всё по каждому слову. Колонка «лист» пустая — слово в работе, число — номер листа. Слова можно править прямо здесь.
- **Листы** — какие листы и когда отправлены.
- **Журнал** — вызовы моделей и отправки файлов, для поиска проблем.
- **Настройки** — `fontSize` (размер шрифта в Word, по умолчанию 12) и `maxWords` (не больше стольких слов на лист). Сколько слов влезает на А4, бот считает сам.
